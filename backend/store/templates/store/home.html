Elegant Jewellery Store

The backend API is running. This page is served by Django; the storefront itself is the React app in frontend/.

Available endpoints:

  • /products/ — list products
  • /register/ — create an account (POST)
  • /login/ — authenticate (POST)
  • /chat/ — simple rule-based chat (POST)
  • /chatbot/ — AI shopping assistant (POST)
  • /admin/ — Django admin
